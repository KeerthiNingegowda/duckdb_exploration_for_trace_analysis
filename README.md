# duckdb_exploration_for_trace_analysis
A quick exploration of duckdb to analyze traces for agents

This repo consists of exploration of duckdb as a tooling option for analyzing traces from agents. Additionally, also covers some fundamental concepts related to this analytical database

Official documentation can be found at - https://duckdb.org/docs/2.0/

## Fundamentals

### Setup
